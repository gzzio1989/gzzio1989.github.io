バンドフィックスグッジオBandFixGzzio

バランスの悪いバンド録音を、AI がパートごとにばらばらに分解して、 バランスと EQ をととのえて、いいかんじにミックスしなおすアプリです。 ハモリだけを抜き出すこともできます。ボーカルグッジオの姉妹アプリ。 It pulls a badly balanced band recording apart with AI, evens out the levels and EQ, and mixes it back together. It can also lift just the harmony line out. A sister app to VocalGzzio.

Features

できることWhat it does

  • パート分解（AI）Part separation (AI) 最大6パート（ボーカル / ドラム / ベース / ギター / ピアノ / その他）。鳴っていないパートは自動で除外。はやい4パートモードもあります。 Up to six parts - vocals, drums, bass, guitar, piano and other. Parts that are not playing are dropped automatically. A faster four-part mode is included.
  • ハモリ分離（AI）Harmony separation (AI) ボーカルをさらに「メインボーカル」と「ハモリ・コーラス」に分解。ハモリだけ WAV で書き出せます。 Splits the vocal again into a lead and the harmony or backing parts, and exports the harmony on its own as a WAV.
  • ハモリの声部分解（実験的）Splitting harmony into voices (experimental) ピッチ解析でハモリを「上ハモ / 下ハモ」（2〜4声）に分けます。 Uses pitch analysis to separate the harmony into upper and lower lines - two to four voices.
  • ドラムの細分化（AI）Drum breakdown (AI) ドラムをキック / スネア / タム / ハイハット / ライド / クラッシュに分解します。 Breaks the kit down into kick, snare, toms, hi-hat, ride and crash.
  • 管楽器の自動判定（AI）Horn detection (AI) 「その他」の中からサックス等の管楽器を見つけ、独立したトラックとして分離します（OFF にもできます）。 Finds saxophones and other horns hiding in the "other" bucket and gives them their own track. Can be turned off.
  • おまかせモードAutomatic mode 各パートのラウドネス（LUFS）を測って目標バランスへ自動補正し、本格的なミックス処理まで自動で適用します。 Measures each part's loudness, corrects it towards a target balance, and applies a full mix chain for you.
  • じぶんでモードManual mode おまかせの結果から、音量 / 左右 / ミュート / 3バンド EQ /「きらきら✨」などの雰囲気プリセットを自由に調整できます。 Start from the automatic result, then adjust level, pan, mute, a three-band EQ and character presets per part.
  • 動画にもどすBack into the video MP4 / MOV / MKV / AVI / WEBM を直接読み込んで、音だけ直して書き戻します。映像は再エンコードなしのコピーなので画質そのまま・高速です。 Load a video directly, fix only the audio and write it back. The picture is copied without re-encoding, so quality is untouched and it is fast.
  • 複数曲キューBatch queue 何曲でも予約して順番に自動分解。処理中のキャンセルもできます。できた曲から順に調整できます。 Queue as many songs as you like and let it work through them. You can cancel mid-run and start adjusting finished songs right away.
  • GPU 対応GPU support NVIDIA GPU があれば自動で使用（数十秒／曲）。無い場合も CPU で動きます（数分／曲）。 Uses an NVIDIA GPU automatically when present - tens of seconds per song. Without one it still runs on the CPU in a few minutes.

How to use

つかいかたHow to use

  1. きょくをドラッグ&ドロップDrop a song in
    WAV / MP3 / FLAC / OGG などのほか、動画ファイルもそのまま置けます。 WAV, MP3, FLAC, OGG and video files all work.
  2. 「ばらばらにする♪」を押してまつPress separate and wait
    GPU があれば数十秒、CPU でも数分です。☕ Tens of seconds with a GPU, a few minutes on CPU.
  3. ミックスこうぼうで仕上げるFinish it in the mix room
    おまかせモードならそのまま「ためしにきく」→「ミックスをかきだす」。じぶんでモードならパートごとに触ってから書き出します。 In automatic mode just preview and export. In manual mode, adjust each part first.
  4. ハモリだけほしいときはJust want the harmony?
    「🎶 ハモリだけかきだす」を押すと、ハモリ・コーラスだけが WAV で出てきます。 Press the harmony-only export and you get the backing parts as their own WAV.

Inside

中でやっている処理What happens inside

実際のスタジオや一流プラグインが行っている処理を実装しています。おまかせモードでは下記が自動で、じぶんでモードでは量を手で変えられます。 The chain follows what real studios and serious plugins do. Automatic mode applies it for you; manual mode lets you set the amounts.

パートごと（チャンネルストリップ）Per part (channel strip)

処理順も実務の定石どおり（定位 → レベラー → ゲート → トランジェント → EQ → 共振抑制 → ディエッサー → コンプ → パラレルコンプ → サチュレーション → ゲイン → パン）。 In the usual professional order: placement, leveller, gate, transient, EQ, resonance control, de-esser, compressor, parallel compression, saturation, gain, pan.

ノイズゲートNoise gate 音のない所のカブリ・分離ノイズを掃除（-45dB）Cleans bleed and separation artefacts in the gaps
トランジェントシェイパーTransient shaper 立ち上がりと余韻を独立して増減（差分エンベロープ方式）Attack and sustain shaped independently
ぶつかり自動解消Automatic unmasking 歌を覆っている楽器の帯域を検出し、楽器側を最大3dB削るFinds where instruments cover the vocal and dips them by up to 3 dB
共振抑制Resonance control 曲を通して居座る共振だけを検出して動的に削るDetects resonances that sit through the whole song and reduces them dynamically
ディエッサーDe-esser 5.5〜9.5kHz の歯擦音のみ最大7dB抑制（ゼロ位相の帯域分割）Up to 7 dB on sibilance between 5.5 and 9.5 kHz, using a zero-phase split
パラレルコンプParallel compression ニューヨーク式。潰した音を原音に混ぜて密度を出すNew York style - the squashed signal blended back in for density
サチュレーションSaturation 4倍オーバーサンプリングでエイリアシングを防止（テープ／真空管）Tape and tube flavours, 4x oversampled to avoid aliasing

マスターバスMaster bus

グルーコンプGlue compressor ミックスをなじませる（ナチュラル1.7:1／パンチ2.2:1、GR 1〜3dB）Pulls the mix together, 1 to 3 dB of reduction
マルチバンドコンプMultiband compressor 4バンド。帯域別の時定数（低域60ms〜高域4ms）、各帯域 -3〜4dB上限Four bands with per-band timing, capped at 3 to 4 dB each
M/Sステレオ幅・ベースモノ化Stereo width and bass mono サイドの低域は自動カット。110Hz以下はセンターへ（ゼロ位相分割で位相のにじみなし）Lows below 110 Hz are centred with a zero-phase split, so nothing smears
ラウドネス調整Loudness -14 LUFS（配信）／-9 LUFS（CD）へ。誤差0.2dB以内に収束Targets −14 LUFS for streaming or −9 LUFS for CD, within 0.2 dB
トゥルーピークリミッターTrue peak limiter ITU-R BS.1770-4 準拠の4倍オーバーサンプリング検出＋先読み4x oversampled detection to ITU-R BS.1770-4, with lookahead

品質メーターQuality meters

書き出す前に、しあがりを実際に測って表示します。 Before you export, it measures the result and shows you the numbers.

LUFS体感音量。配信サービスの基準に合っているかPerceived loudness against streaming targets
dBTPサンプル間まで含めた真のピーク。MP3変換時の歪みを防ぐ指標True peak including between samples - the number that keeps MP3 conversion clean
LRA曲中の音量のばらつき。小さすぎるとのっぺりした音How much the level moves across the song
PLRピークと音量の差。8dB未満だと潰れすぎの目安Peak to loudness - under 8 dB usually means it is over-squashed
相関Correlation モノ再生との相性。マイナスだとモノで音が消える危険Mono compatibility - negative values mean parts vanish in mono
