ディスクグッジオDiskGzzio

Windows の「もう使ってないファイル」を自動で見つけて、中身を確認してから安全に掃除するアプリです。 音楽プロジェクト・録音・VST・ドキュメントには一切触りません。インストール不要、展開するだけで動きます。 Finds the files Windows no longer needs, shows you the list, and cleans up only what you tick. It never touches your projects, recordings, plugins or documents. No installer - just unzip and run.

Safety

安全設計（いちばん大事なところ）How it stays safe

  • 勝手には消しませんNothing happens silently スキャン → 一覧で確認 → ボタンを押して掃除、の順です。押すまで何も起きません。 Scan, look at the list, then press the button. Nothing is removed until you do.
  • 既定は「ごみ箱へ移動」It moves things to the recycle bin 間違えても、ごみ箱から元に戻せます。 If you change your mind, everything can be restored.
  • 全部ログに残りますEverything is logged 消したものは %APPDATA%\DiskGzzio\logs に記録されます。 A record of every removal is written to the log folder.
  • ユーザーデータには触れませんYour own files are off limits 音楽プロジェクト・録音・VST・ドキュメントなどの領域には一切触れません。 Projects, recordings, plugins and documents are never in scope.

How to use

つかいかた（3ステップ）Three steps

  1. 起動するStart it
    Start_DiskGzzio.bat をダブルクリック。黒い小窓が最小化で開きますが、閉じるとアプリも終わるのでそのままに。 Double-click the start batch file. A small console window stays minimised - leave it open, closing it quits the app.
  2. スキャンして確認するScan and review
    「スキャン」→ 一覧の中身を確認 →「選択した項目を掃除する」。 Press Scan, read through the list, then clean the items you selected.
  3. 空き容量を実際に増やすActually free the space
    「ごみ箱を空にする…」を押します。ここだけ復元できないので、中身を確認してから。 Empty the recycle bin. This step cannot be undone, so check the contents first.

C:\Windows\Temp まで掃除したいときは Start_DiskGzzio_Admin.bat で起動してください（UAC の確認が出ます）。 To include the Windows temp folder, launch the admin batch file instead - Windows will ask for permission.

Scope

自動判定の対象What it looks at

一時ファイル（ユーザー）Temp files (user) %TEMP% — 7日より前older than 7 days
一時ファイル（Windows）Temp files (Windows) C:\Windows\Temp — 7日より前・管理者起動時のみolder than 7 days, admin launch only
クラッシュダンプCrash dumps %LOCALAPPDATA%\CrashDumps
Windowsエラー報告Windows error reports WER
シェーダーキャッシュShader cache D3DSCache / NVIDIA / AMD（使うと自動で再生成されます）Rebuilt automatically the next time you need it
ダウンロード整理候補Download candidates 180日以上未使用。一覧表示のみ・既定は未チェックUnused for 180 days or more - listed only, never ticked by default

サムネイルキャッシュ、Windows Update の残骸、休止ファイルなどは対象外です。これらは Windows 標準の「ストレージセンサー」が安全に処理してくれるので、併用するのがいちばん確実です。 Thumbnail caches, Windows Update leftovers and the hibernation file are deliberately out of scope - Windows' own Storage Sense handles those safely, so use both together.
