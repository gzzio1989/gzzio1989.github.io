ほんやくブリッジHonyaku Bridge

相手の声を聞き取って日本語の音声で読み上げ、こちらの日本語を相手の言葉の音声にして送る、 リアルタイム音声翻訳プラグインです。オンラインセッションや配信で、言葉が違う人と話すために作りました。 A real-time speech translation plugin. It listens to the other person and reads them back to you in Japanese, and turns your Japanese into their language on the way out. Built for talking across languages in online sessions and streams.

Features

できることWhat it does

  • きく (Listen) モードListen mode 相手の声を聞き取り、言語を自動で見分けて、日本語の音声で読み上げます。 Picks up the other person, works out what language it is, and speaks it back to you in Japanese.
  • はなす (Speak) モードSpeak mode あなたの日本語を、相手の言語に翻訳した音声に変えて送ります。翻訳先は「きくモードが直近に聞き取った言語」に自動で合います。 Turns your Japanese into speech in their language. The target follows whatever Listen mode heard most recently.
  • 逐次通訳の方式Consecutive, not simultaneous 話し終えて0.6秒ほど間が空くと、その発話が翻訳されて数秒後に流れます（同時通訳ではありません）。 When you stop for about 0.6 seconds, that phrase is translated and played a few seconds later.
  • 料金はかかりませんNo running cost 翻訳と読み上げにインターネットを使いますが、すべて無料サービス構成です。 Translation and speech use the internet, but the whole chain runs on free services.
  • 3つの形式で同梱Three plugin formats VST3・VST2 (dll)・CLAP を同梱。お使いのソフトが読める形式を入れてください。 VST3, VST2 and CLAP are all included - install whichever your host can load.
  • 元の声とのバランス調整Balance with the original voice 翻訳音声の再生中だけ元の声を下げる「ダッキング」つき。翻訳音声だけを送ることもできます。 Ducks the original voice while the translation plays, and you can send only the translation if you prefer.

How to use

つかいかたHow to use

2つのパーツで動きます。補助アプリ（音声認識・翻訳・読み上げの本体）と、プラグイン（音の橋渡し役）です。 It comes in two parts: a helper app that does the recognition, translation and speech, and a plugin that carries the audio between them.

  1. 補助アプリを先に入れるInstall the helper app first
    server フォルダを好きな場所にコピーして setup.bat をダブルクリック。Python が無ければ自動で案内が出ます。 Copy the server folder anywhere and run setup.bat. It offers to install Python if you do not have it.
  2. プラグインを入れるInstall the plugin
    HonyakuBridge.vst3 をフォルダごと C:\Program Files\Common Files\VST3\ へ。同梱の install_vst3.bat を管理者として実行してもOK。 Copy the HonyakuBridge.vst3 folder into your VST3 directory, or run the bundled installer batch as administrator.
  3. 補助アプリを起動しておくLeave the helper running
    start.bat を実行。初回だけ音声認識モデル（約500MB）のダウンロードで数分かかります。「プラグインの接続を待っています…」と出たら準備完了。使う間はこの窓を開いたままに。 Run start.bat. The first launch downloads a speech model of about 500 MB. Keep the window open while you use it.
  4. モードを選ぶPick a mode
    プラグインの Mode を「きく」か「はなす」に。あとは普通に話すだけです。 Set the plugin's Mode to Listen or Speak, then just talk.

Wiring

つなぎ方How to wire it up

SYNCROOM (Ver.2)

SYNCROOM Ver.2 は VST3 プラグインを直接挿せます。はなすなら、オーディオ設定のマイク入力に挿して Mode を Speak に。 それだけで、あなたの日本語が相手の言語の音声になって流れます。 SYNCROOM Ver.2 loads VST3 plugins directly. For Speak, insert it on the mic input and set the mode - your Japanese goes out in their language.

Discord / REALITY / Cluster など（VSTを挿せないアプリ） Discord, REALITY, Cluster and other apps that cannot load plugins

無料の VST ホスト（Cantabile Lite、Element など）と仮想オーディオケーブル（VB-CABLE など）で音を経由させます。 Route the audio through a free VST host such as Cantabile Lite or Element, plus a virtual audio cable such as VB-CABLE.

プラグインのつまみPlugin parameters

Modeきく（相手→日本語）／はなす（日本語→相手）Listen (partner to Japanese) or Speak (Japanese to partner)
TTS Volume翻訳音声の音量（0〜2）Volume of the translated speech
Original Volume元の声の音量。はなすモードで 0 にすると翻訳音声だけが相手に届きますVolume of the original voice. Set to 0 in Speak mode to send only the translation
Duck Amount翻訳音声の再生中、元の声をどれだけ下げるかHow much the original voice drops while the translation plays
Send Audioオフにすると音声を補助アプリへ送りません（一時停止・プライバシー用）Turn off to stop sending audio to the helper - for pauses and privacy
