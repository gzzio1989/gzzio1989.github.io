できることWhat it does

声にまつわる作業を、一つの画面で。Everything the voice needs, on one screen.

ノイズ取りから音程補正、声変えまで。プラグインを何枚も重ねなくても、配信や録音でよく使う処理が順番に並んでいます。 From noise removal to pitch correction and voice changing — the processing you reach for while streaming or recording, in the order you use it.

ピッチ補正Pitch correction

歌のピッチを検出して、選んだキー／スケールへ自動で補正。フォルマントを保つので声の性別感は変わりません。「速さ」でケロケロ〜自然を調整できます。 Detects your pitch and snaps it to the key and scale you pick. Formants stay put, so the voice keeps its character. The Speed control takes you from hard robotic steps to a natural glide.

ノイズ除去（LEARN）De-noise (LEARN)

黙ったまま LEARN を押すと約1.5秒で部屋のノイズを学習。4帯域の適応型で、エアコンや PC のファン音を削ります。遅延は増えません。 Stay quiet, press LEARN, and it profiles your room in about 1.5 seconds. Four adaptive bands then pull down fan and air-conditioner noise, with no added latency.

声質・マイク・シーンVoice, mic and scene presets

声質10種 × マイク特性20種（ライブ標準・放送ダーク・スタジオ定番など）× シーン3種を掛け合わせるだけで土台ができます。ワンプレス自動設定も。 Ten voice types x twenty mic characters (live standard, broadcast dark, studio classic and so on) x three scenes combine into a starting point. There is also a one-press auto setup that listens and decides for you.

2段コンプ＋ディエッサーTwo-stage compression + de-esser

ピーク圧縮と平準化を分けて、音量差の激しい歌でも聴きやすく。耳に刺さる「サ行」だけを狙って抑えます。 Peak control and levelling run as separate stages, so loud phrases sit with quiet ones. The de-esser targets sibilance only.

声変え・ハモリ9種Voice change and 9 harmony modesNEW 2.0.0

ピッチとフォルマントを別々に動かせるので、性別感だけ変えることもできます。ハモリは上下3度・上下6度・5度・3度＋5度・おまかせ・反行の9種類。「ハモだけ」で原音を消してハモリだけ録るのも、サビリフトで自動的に盛り上げるのもできます。 Pitch and formant move independently, so you can shift the character without changing the note. Nine harmony modes - thirds and sixths above or below, fifths, both, auto, and contrary motion - plus harmony-only output and the automatic Chorus Lift.

空間・キャラ声Space and character FX

リバーブ（スプリング／シマー含む）、テンポ同期ディレイ、ダブラー、メガホン、ロボ声。歌でも雑談でも遊べます。 Reverb (including spring and shimmer), tempo-synced delay, doubler, megaphone and robot voice — for songs and for goofing around on stream.

どこがどう変わってきたかWhat changed, and when

新しい順。バージョンごとに、何がどう変わったかをまとめています。 Newest first, with what actually changed in each release.

  1. v2.10.0

    音源モードと、点検 — それと「痩せる・シャリつく」の原因Source modes, Checkup - and the cause of "thin and harsh"

    • 「音が痩せる・シャリつく・小さい・上げると潰れる」の原因が分かりました。ノイズ床の学習（LEARN）が、声の入った状態のまま固まって保存されていたのが正体です。実測すると、歌いながら覚えさせた場合は音量−5.35dB／低域60-250Hz−4.75dB／中域−7.32dB／山と谷の差+3.50dB。下が落ちて上だけ残るので「痩せる・シャリつく」、全体が下がるので「小さい」、山と谷が開くので「上げると潰れる」。本当に静かなときに覚えさせた場合は0.00dB＝機能そのものは正しく、汚れた学習が固定されていただけでした。しかも引き金はLEARNボタンではなく「10秒おまかせ」で、押してから0.5〜2.0秒のあいだに自動で学習しています。覚えた床は保存され、元に戻すコードがどこにも存在しなかったため、再起動しても版を上げても直りませんでした。 We found what makes the sound go thin, harsh, quiet, and crushed when you push it. The noise-floor LEARN was capturing while the voice was still there, then freezing and saving that forever. Measured against not learning at all: level −5.35 dB, low end (60-250 Hz) −4.75 dB, mids −7.32 dB, crest +3.50 dB. The bottom drops and the top stays, so it sounds thin and harsh; everything drops, so it sounds quiet; the crest opens up, so pushing the mic makes it crush. Learned in true silence the difference is 0.00 dB - the feature was fine; a dirty capture had been frozen in place. The trigger was not the LEARN button but the 10-second Auto Setup, which learns automatically 0.5 to 2.0 s after you press it. The result was saved, and no code anywhere set it back, so it survived restarts and updates.
    • 4つ直しました。①1.5秒の最大値ではなく中央値を床にする（一瞬の物音で決まらない）②中央値が−45dBFSを超える、または95%点との開きが12dBを超えるなら採用せず、理由と実測値を画面に出す ③覚えている間だけ「学習ずみ」ボタンが出て、押すと自動追従に戻る ④すでに汚れた床が保存されている設定は、読んだ時点で捨てる。④のおかげで、いま症状が出ている方は更新するだけで直ります。採用しなかったときは音が1ビットも変わりません（実測 最大差 0.000e+00）。 Four fixes. (1) The floor is now the median of the 1.5 s capture, not the maximum, so a single noise cannot set it. (2) If the median is above −45 dBFS, or the spread to the 95th percentile exceeds 12 dB, the capture is rejected and the screen says why, with the measured level. (3) While a profile is stored a "Learned" button appears; press it to go back to automatic tracking. (4) A stored floor that could not possibly be room noise is discarded on load - so if you have the symptom today, updating fixes it. A rejected capture changes the audio by exactly nothing (measured max difference 0.000e+00).
    • 音源モードを付けました（うた／アコギ／しゃべり）。プリセットではありません。ツマミの位置はそのままで、狙う場所だけが変わります。こもりは、うた300Hz／アコギ220Hz（胴鳴り）／しゃべり350Hz。かたさは、うた3.2kHz／アコギ2.5kHz（ピックのカリつき）。ぬけは、うた4.2kHz／アコギ3.5kHz（弦の輪郭）／しゃべり2.8kHz（明瞭度）。ディエッサーは、うたはサ行（5.2k→6.5k）、アコギはフレットとピックの音（3k→4k）を探します。なめらかの見張る範囲も、うた900Hz〜9kHzに対しアコギは250Hz〜6kHz。アコギではピッチ補正・ハモリ・ボイス変換を通しません（和音の鳴る楽器に声用のピッチ検出を掛けると別の弦へ飛び移って音程がふらつくため。切ってあるので遅延も0のまま）。しゃべりではひびき・やまびこを切ります。「うた」はv2.9.0と1ビットも同じです（7シナリオでmd5一致を確認）。 New source modes: Vocal, Acoustic Guitar, Talk. Not presets. The knobs stay where they are; only what they aim at changes. Mud: 300 Hz for voice, 220 Hz for a guitar body, 350 Hz for speech. Harsh: 3.2 kHz for voice, 2.5 kHz for pick attack. Presence: 4.2 kHz for voice, 3.5 kHz for string definition, 2.8 kHz for speech intelligibility. The de-esser hunts sibilance (5.2k, ducking 6.5k) for voice but fret and pick noise (3k, ducking 4k) for guitar. The resonance tamer watches 900 Hz-9 kHz for voice and 250 Hz-6 kHz for guitar. Guitar mode does not run pitch correction, harmony or voice change - feeding a chordal instrument into a vocal pitch detector makes it jump between strings and wobble - so latency stays at zero. Talk mode drops reverb and echo. Vocal mode is bit-identical to v2.9.0 (md5 match across seven scenarios).
    • 「点検」ボタンにまとめた4つ。ゼロ遅延の自己証明＝「測る」を押すと約1秒だけ出力を黙らせ、その間にインパルスを流して申告値・実測値・その差を出します。差が0なら「この環境で実測0サンプル」と言い切れます。報告セットの書き出し＝版・サンプリング周波数・ブロック・申告遅延・いまの設定ぜんぶをテキストに。使われ方＝どの機能を何秒使ったかを手元のファイルに貯めます（送信は一切しません。あなたが報告セットを送ってくれたときだけ届きます）。名前ごとの設定＝ホストのトラック名、無ければ自分で打った名前をキーに設定を覚えます。 Four things under the new Checkup button. Prove it yourself: press Measure and the output mutes for about a second while an impulse runs through the chain, reporting declared latency, measured latency and the gap. A gap of zero means zero samples measured on your machine. Report export: version, sample rate, block size, declared latency and every current setting as plain text. Usage log: seconds spent in each feature, kept in a local file - nothing is ever transmitted; it only reaches us if you send the report yourself. Per-name settings: keyed on the host track name, or a name you type when there is none.
    • 距離ならし（近接効果の自動補正）。マイクに近づくと低音が増え、離れると痩せます。40秒かけて「いつもの量」を覚え、そこからのズレだけを220Hzの棚と音量で戻します。覚えた量に寄せるだけなので声質は変えません。0%（既定）は完全な素通し（実測 差0）で、追加の遅延もありません。 Distance Evener. Lean into the mic and the low end swells; back away and it thins. This learns your usual balance over 40 seconds and corrects only the drift, using a 220 Hz shelf plus a little gain. It moves you back to your own sound rather than imposing one. At 0% (the default) it is a true bypass - measured difference zero - and adds no latency.
    • もう1件、検証中に見つけた不具合。おまかせの「こもり取り」「かたさ取り」が一度も効いていませんでした。ツマミの範囲は−12〜0dB（マイナスが削る）なのに、おまかせは0〜8のプラスを書き込んでいて、範囲に丸められて必ず0になっていました。「おまかせを掛けてもシャリつきが取れない」の一因です。符号を直しました。 And one more bug, found while testing the source modes. Auto Setup's mud dip and harsh cut had never done anything. Those knobs run from −12 to 0 dB, where negative means cut - but Auto Setup was writing positive values from 0 to 8, which clamped to zero every time. That is part of why Auto Setup never took the edge off. The sign is fixed.
  2. v2.9.0

    セッションモード — 追加遅延を0サンプルに固定Session mode - added latency pinned at 0 samples

    • 「低遅延」ボタンを廃止しました。あれはピッチ系の遅延を768→384サンプル（17.4→8.7ms）に半分にするものでしたが、オンラインセッションで快適とされる往復30msはネットとパソコンを通した合計の実測値です。オーディオインターフェースのAD/DAとバッファだけで7〜8ms使うので、プラグインに許される追加遅延は実質ゼロ。つまり8.7msは「半分になった」のではなくまだ足りないのに、低い声のざらつきという代償だけが残っていました。 The Low Latency button is gone. It halved the pitch-tool delay from 768 to 384 samples (17.4 to 8.7 ms), but the 30 ms round trip that feels comfortable in an online jam is measured across the network and the computer. Your interface alone eats 7-8 ms, so the budget left for a plug-in is effectively zero. 8.7 ms was not "half the problem" - it was still too much, and you paid for it with grainier low notes.
    • かわりに「セッション」スイッチを付けました。ONの間は、遅延をふやす3つ（ピッチ補正・ボイス変換・ハモリ／5人ユニゾン）を素通しにして、追加遅延を0サンプルに固定します。スイッチの値そのものは変えないので、セッションを抜ければ元どおり鳴ります。止めている間はその3つのツマミが灰色になるので、「見えているのに効いていない」になりません。 In its place there is a Session switch. While it is on, the three tools that add delay - pitch correction, voice change and harmony/unison - are bypassed and added latency is pinned at 0 samples. The switch does not touch their values, so leaving session mode brings everything back. Those controls grey out while suspended, so nothing looks active while being silent.
    • 「追加遅延 +0.0 ms」を画面に常時表示します。ゼロ遅延は宣伝文句ではなく測った数字なので、隠さず出すことにしました。0なら緑、足していれば黄色。再生中にピッチ補正をONにすればその場で+17.4msに変わります（申告値ではなく、いま実際に遅れている値です）。 An "added latency" badge is now always on screen. Zero latency is a measured number here, not a slogan, so the number is shown: green at zero, amber when something is adding delay. Switch on pitch correction mid-playback and it jumps to +17.4 ms straight away - it reports what you are actually hearing, not what was declared at load time.
    • バグを1件直しました：ハモリだけONにすると歌だけ17.4ms走っていました。ハモリ（5人ユニゾン）だけをONにすると、プラグインはホストへ「768サンプル遅れます」と申告するのに、実測すると主メロのピークは0サンプル＝まったく遅れていませんでした。ハモリは主メロの横に声を足す並列処理なので、主メロは遅れません。申告だけが嘘をついていたため、DAWがトラックを17.4ms前へ引っ張って歌だけ走り、さらにMixの原音そろえも同じ値を見ていたのでハモリのときだけコムフィルタ（スカスカ）が再発していました。 One bug fixed: harmony alone made the lead vocal run 17.4 ms early. With only harmony/unison enabled, the plug-in told the host it had 768 samples of latency - but the measured peak of the lead vocal was at 0 samples. Harmony adds voices beside the lead; it never delays the lead itself. The host believed the false report and pulled the track 17.4 ms early, and because the dry-mix alignment read the same value, the comb filter fixed in v2.8.0 came back whenever harmony was used.
  3. v2.8.1

    長時間の「ジー」への対策 — 調査と保険Countermeasures for the long-session buzz - investigation and insurance

    • 「長い時間使うとジーが走る」というご報告を受けた回です。最有力の原因は、v2.8.0で直した「音声処理の中の毎回のメモリ確保」でした。締め切り2.8ms（124サンプル）の処理に数十回のmalloc/freeが走っており、確保がたまに遅れるとブロックが落ち、連続するとブロック周期（約355Hz）の「ジー」に聞こえます。ヒープはセッションが長いほど荒れるため「長時間で出る」とも合います。 This release follows up a report of a buzz creeping in after hours of use. The prime suspect is the per-block heap allocation fixed in v2.8.0: dozens of malloc/free calls inside a 2.8 ms deadline. A slow allocation drops a block, and repeated drops at the ~355 Hz block rate sound exactly like a buzz - worse as the session heap ages.
    • 長時間シミュレーションを新設しました。ハム除去に歌＋本物のハムを20分（息継ぎの残りカスは序盤-63.4dB→終盤-66.1dBで悪化なし）、ボイス変換に8分、内部発振器に6時間ぶん（振幅ずれ3.6e-7）。音の処理そのものは長時間でも劣化しないことを数値で確認しています。 A new long-run simulation feeds the hum remover 20 minutes of singing plus real hum (gap residue -63.4 dB early vs -66.1 dB late - no build-up), the voice changer 8 minutes, and the internal oscillators 6 hours' worth (amplitude drift 3.6e-7). The DSP itself does not degrade over time.
    • 保険をふたつ。ジー音の内部状態が万一壊れたら0.1秒で自動的に作り直す自己回復を追加。インストーラも、上書き時に古いVST3バンドルを消してから入れるようにしました（「新しい版を入れたのに画面の版表示が古いまま」の一因を断つため）。 Two pieces of insurance. The hum remover now self-heals within 0.1 s if its state is ever corrupted, and the installer wipes the old VST3 bundle before copying the new one - closing one path to "I installed the update but the version label is still old".
  4. v2.8.0

    つかいやすさと安定性 — ひと回り点検して18個直しましたUsability and stability - one full pass, 18 fixes

    • マイク音量が、本当にいちばん手前で効くようになりました。説明文には「ぜんぶの処理のいちばん手前で掛ける」と書いてあったのに、実際はゲート・ノイズ除去・ボイス変換のあと、しかもINメーターを取ったあとに掛けていました。そのため「マイク音量を上げてもINメーターが動かない」「ゲートのしきい値が入力に追いつかない」という状態でした。 Mic Volume now really is the first thing in the chain. The manual said it was applied at the very start, but it actually ran after the gate, the de-noiser and the voice changer - and after the IN meter was read. FAQ

DAW にプラグインが出てきませんMy DAW does not list the plugin

プラグインの再スキャンを実行してください。SONAR 2025.12 で出てこなかった問題は v1.9.0 で修正済みです。古い版をお使いなら更新してください。 Run a plugin re-scan first. If you are on SONAR 2025.12, update to v1.9.0 — that release fixes the case where the plugin was silently skipped.

ピッチ補正はどう設定すればいいですかHow should I set up pitch correction?

キーとスケールを曲に合わせ、補正 80%・速さ 30% から始めてください。ケロケロにしたいときは速さを 0 に近づけます。曲のキーが分からなければ「キー検出」を押すと入ります。 Match the key and scale to the song, then start at Amount 80% and Speed 30%. Move Speed toward 0 for the hard robotic effect. If you do not know the key, press Detect key and it fills itself in.

Mac では使えますかDoes it run on macOS?

現在サポートしているのは Windows のみです。Mac 版の提供予定は未定です。 Windows is the supported platform today. There is no announced plan for a macOS release.
